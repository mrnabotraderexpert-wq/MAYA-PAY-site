Ouvrez MAYA-PAY sur votre téléphone

MAYA-PAY sert aux paiements mobiles (Orange Money, Moov Money) et fonctionne uniquement sur téléphone.

Créer un lien de paiement

Votre client paie depuis son compte Orange Money ou Moov Money vers le vôtre. L'argent ne passe jamais par MAYA-PAY.

Le client initie, pas MAYA-PAY. MAYA-PAY prépare seulement le code ; c’est le client qui le valide avec son code PIN.

Activation Sarali

Avant de fournir votre numéro, veuillez l’enregistrer comme numéro marchand.

Voici la procédure d'activation Sarali :

  1. 1

    1. Composez #143# sur votre puce Orange.

  2. 2

    2. Sélectionnez l'option de souscription Sarali / petit commerçant.

  3. 3

    3. Confirmez l'inscription en suivant les instructions.

  4. 4

    4. Votre numéro de téléphone devient utilisable comme code marchand.

Renseignez au moins un des deux. Vos numéros sont cachés : ni dans le lien, ni affichés à vos clients. Le client ne verra que les opérateurs pour lesquels vous avez saisi un numéro.

Votre nom et votre photo s'affichent sur la page de paiement de votre client : il reconnaît tout de suite à qui il paie.
